# Alcance del proyecto

Este proyecto es la base inicial de un sistema que, en versiones futuras, podría incluir:

1. **Registro de recursos**: permitir agregar nuevos recursos académicos (libros, artículos, videos, sitios web, herramientas) con sus metadatos.
2. **Búsqueda y filtrado**: consultar recursos por tipo, tema, nivel o autor/fuente.
3. **Exportación de catálogo**: generar reportes o listados en formatos como CSV o PDF.
4. **Integración con APIs externas**: usar `requests` para validar enlaces o importar metadatos automáticamente (por ejemplo, desde repositorios académicos).
5. **Interfaz de consola mejorada**: usar `rich` para mostrar el catálogo de forma visual y organizada en terminal.
