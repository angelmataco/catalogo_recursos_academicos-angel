# Criterios de clasificación de recursos académicos

1. **Tipo**: libro, artículo, video, sitio web, herramienta de software.
2. **Tema**: área de conocimiento a la que pertenece el recurso (ej. inteligencia artificial, matemáticas, programación).
3. **Nivel**: básico, intermedio, avanzado.
4. **Autor o fuente**: persona, institución o plataforma que produjo el recurso.
